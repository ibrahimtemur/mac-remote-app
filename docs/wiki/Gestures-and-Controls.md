The Mac Remote mobile interface is designed to closely mimic the physical Apple Magic Trackpad while offering additional quick-action remote shortcuts.

---

## 👆 Trackpad Gestures

| Gesture | Action | Description |
| :--- | :--- | :--- |
| **One Finger Drag** | Move Cursor | Smooth cursor motion with velocity smoothing. |
| **Single Tap** | Left Click | Clicks at current cursor position with light haptic feedback. |
| **Two Finger Tap** | Right Click | Opens macOS context menus. |
| **Two Finger Drag** | Scroll Page | Vertical and horizontal smooth natural scrolling. |
| **Double Tap & Drag** | Drag & Drop | Grabs windows, files, or selections and moves them. |
| **Selection Mode** | Text Selection | Tap the **Select Text** button, then drag across text to highlight. |

---

## 🎛️ Physical Click Buttons
Below the main touch canvas, dedicated tactile buttons are provided for convenience:
- **Left Click (`Sol Tık`):** Standard primary click.
- **Double Click (`Çift Tık`):** Fast double-click (opens files, selects whole words).
- **Right Click (`Sağ Tık`):** Secondary context click.
- **Scroll Up / Down (`Yukarı / Aşağı Kaydır`):** Discrete scroll wheel increments.

---

## ⌨️ Keyboard Input
Tap the **Toggle Keyboard** (`Klavye`) icon in the action bar:
- Open your native mobile keyboard.
- Type full sentences or words and send them directly to your Mac.
- Use quick-access buttons for:
  - **Space (`␣ Space`)**
  - **Backspace (`⌫ Backspace`)**
  - **Enter (`⏎ Enter`)**
  - **Escape (`Esc`)**

---

## 🎬 Media & Presentation Controls
A dedicated floating/collapsible media bar provides controls that trigger native macOS system events:
- **Play / Pause (`Oynat / Durdur`):** Toggles playback in Spotify, Apple Music, YouTube, VLC, etc.
- **Previous / Next Track:** Skip between songs or presentation slides.
- **10s Rewind / 10s Forward:** Jump backward or forward in media players.
- **Volume Up / Volume Down / Mute:** Control system master volume.

---

## 🖥️ Screen Streaming & Quality Settings
In the top control bar, tap the **HD Quality** icon to choose the live desktop preview resolution:
- **⚡ Low (800p):** Lowest bandwidth, ultra-low latency, ideal on weak Wi-Fi or cellular connections.
- **⚖️ Medium (1200p):** Balanced performance for general tasks.
- **✨ High (1600p):** Sharp rendering, crisp text readability.
- **💎 Ultra HD (2200p):** Maximum detail, crystal-clear Retina fidelity.
